# AuraWatch Pro - Página de Vendas

Este repositório contém a página de vendas de alta conversão para o **AuraWatch Pro**, um smartwatch premium construído com corpo de titânio e cristal de safira.

## 🚀 Tecnologias Utilizadas

- **HTML5** & **CSS3** (Estilização baseada em design moderno)
- **Tailwind CSS** (Carregado via CDN para prototipação e estilização ágil)
- **Motion** (Biblioteca de animação moderna em JavaScript via CDN)
- **Canvas 2D** (Renderização e animação do relógio analógico funcional em tempo real)

## 📦 Como Executar o Projeto Localmente

Por ser uma página puramente estática, você pode executá-la de duas formas:

1. **Abertura Direta**: Basta abrir o arquivo `index.html` em qualquer navegador web.
2. **Servidor Local (Recomendado)**: Utilize qualquer extensão de Live Server (como a do VS Code) ou rode o comando abaixo via terminal caso possua o Node instalado:
   ```bash
   npx opencode --port 26275
   ```
   Ou um servidor estático simples como:
   ```bash
   npx serve .
   ```

## 🌐 Publicação e Sincronização com o GitHub

Para conectar este ambiente local ao seu repositório remoto no GitHub e realizar o envio dos arquivos, execute os seguintes comandos no terminal do seu projeto:

```bash
# 1. Vincular o repositório remoto
git remote add origin https://github.com/fabiotoniati/fono-2605.git

# 2. Renomear a branch padrão para main (caso necessário)
git branch -M main

# 3. Enviar os arquivos para o GitHub
git push -u origin main
```
